# API Básica com Node e Express

### O que é
Esse repositório contém o código final da construção de uma API básica usando Node e Express
O passo a passo da construção está descrito no [blog devNiverse](https://medium.com/devniverse) : Construíndo uma API do zero com Node e Express

### Como rodar

- clone o projeto
- abra o projeto no seu editor de código preferido
- no terminal, instale as dependências do projeto, através do comando: <br>
`npm install`

- execute o servidor, através do comando: <br>
`node index.js`
